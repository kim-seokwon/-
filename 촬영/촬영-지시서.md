# 촬영 지시서 — 하이헤이호 (아동복)

한 품목당 이 순서대로 찍는다. **1~4번은 필수, 5~6번은 여유 있을 때.**
기준 상품: Classic Blouson · Toast Sweat Set · Mochi Raglan Set 같은 상하 세트/단품.

---

## 준비 (촬영 전날)

- [ ] 스팀 다림질 — 접힘 자국은 후보정으로 못 지운다. 여기서 끝내야 한다
- [ ] 택·실밥 제거, 보풀 제거기
- [ ] 컬러별로 전 색상 준비 (바나나·토마토·베이비블루·레몬·멜란지·레드 등)
- [ ] 사이즈는 **한 가지만** 찍는다 (대표 사이즈 = 가장 많이 나가는 것). 나머지는 실측표로 대체
- [ ] 배경지 흰색 + 아이보리 2종
- [ ] 바닥 평면컷용 판 (흰 우드 or 아이보리 종이)

## 1. 누끼컷 (필수) — 목록·썸네일용

| 항목 | 값 |
|---|---|
| 배경 | 흰 배경지, 그림자 최소 |
| 각도 | 정면 정중앙, 카메라 높이 = 옷 중앙 |
| 구도 | 옷 전체 + 상하좌우 여백 10% |
| 소품 | 없음 |
| 컷 수 | 색상당 1컷 |

- 상하 세트는 **세트 전체 1컷 + 상의 1컷 + 하의 1컷**
- 옷걸이 안 쓴다. 바닥에 펴서 위에서 수직으로 찍는다(플랫레이)
- 소매·바지통에 **얇은 종이를 채워** 입체감을 만든다. 납작하면 싸구려로 보인다

## 2. 디테일컷 (필수) — 반품 줄이는 컷

색상 대표 1개만 찍으면 된다. 클로즈업 4컷.

- [ ] 원단 질감 (손가락 한 마디 거리, 실이 보이게)
- [ ] 봉제선·마감
- [ ] 라벨(메인/케어) — 소재·혼용률이 읽히게
- [ ] 부자재 — 지퍼·단추·밴딩·프린트

> 라벨컷이 **문의를 가장 많이 줄인다.** 소재 물어보는 문의가 제일 많다.

## 3. 착용컷 (필수) — 구매를 결정하는 컷

- 모델 사이즈와 실제 키·몸무게를 **반드시 표기** ("120cm / 23kg, L 착용")
- 컷 구성: 정면 전신 · 뒷면 전신 · 앉은 자세 · 걷는 자세(움직임)
- 아이가 웃는 컷보다 **옷이 잘 보이는 컷**이 우선. 얼굴은 잘려도 된다
- 아이 촬영은 **20분 안에** 끝낸다. 그 뒤로는 표정이 무너진다 → 컷 리스트 미리 인쇄해 갈 것

## 4. 사이즈 비교컷 (필수)

- 같은 옷을 **다른 체격 아이 2명**이 입은 컷, 또는 실측 줄자를 올린 플랫레이
- 12M · ~125cm 같은 사이즈 표기가 실제로 어떤 크기인지 보여준다

## 5. 연출컷 (여유 있으면) — 광고·인스타용

- 장소: 집 거실 · 놀이터 · 카페 창가 중 1곳
- 자연광, 정오 피하고 **오전 10시 or 오후 4시**
- 옷 전체가 아니라 **분위기**를 찍는 컷. 광고 소재로 쓴다

## 6. 코디컷 (여유 있으면)

- 이번 시즌 다른 품목과 함께 (예: Toast Sweat Set + Toast hairband)
- 세트 판매·객단가 올리는 컷

---

## 촬영 세팅 (공통)

| 항목 | 값 |
|---|---|
| 조명 | 창가 자연광 + 반사판(흰 폼보드) 반대편. 직사광 금지 |
| 화이트밸런스 | 수동 고정. 자동이면 컷마다 색이 달라진다 |
| 노출 | 흰 배경 기준 +0.3 ~ +0.7 |
| 촬영 형식 | RAW (색 보정 여지) |
| 기준컷 | 첫 컷에 **컬러차트 or 흰 종이**를 같이 찍어둔다 — 후보정 색 기준 |

> ⚠️ **색이 실물과 다르면 반품이 는다.** 특히 베이비블루·멜란지 계열.
> 보정 끝나고 **실물을 모니터 옆에 놓고** 대조한 뒤 업로드할 것.
